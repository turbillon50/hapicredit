CONTEXTO DEL PRODUCTO

Construye HapiControl, una PWA (Progressive Web App) interna de gestión de cartera crediticia y CRM para una empresa de microcrédito (Grupo CAFJA / HapiCredit). La app debe verse y sentirse como una app bancaria de primer nivel — referencia estética: BBVA México app o Nubank. Funciona en navegador mobile y desktop, es instalable como app nativa en iOS y Android, y está 100% en español latinoamericano.

STACK TÉCNICO

Frontend: React + Vite + TypeScript
Estilos: Tailwind CSS v3 (sin componentes externos de UI — todo custom)
Iconos: react-icons únicamente (familias: ri, fi, hi2, md, bi) — CERO lucide-react
Animaciones: Framer Motion para transiciones de página y micro-interacciones
Estado global: React Context + useReducer
Fetching: TanStack Query (react-query) con hooks tipados
Router: React Router v6 con lazy loading por ruta
PWA: vite-plugin-pwa, manifest completo, service worker, iconos 192px / 512px / maskable
Fuentes: Inter via Google Fonts (weights: 400, 500, 600, 700)
Backend ya existe: API REST en Express con PostgreSQL. Solo conectar.

ROLES Y AUTENTICACIÓN

3 roles con vistas completamente diferentes:

admin — acceso total, ve toda la cartera, todos los ejecutivos, métricas globales
ejecutivo/asesor — ve solo sus clientes asignados, su cobranza del día, sus comisiones
cliente — ve solo su crédito activo, historial de pagos, próxima cuota
Auth flow:

Token JWT almacenado en localStorage bajo la key hapi_token
Cada request lleva header Authorization: Bearer <token> — configurar el cliente fetch global al inicio de la app
Pantalla de login: full-screen, fondo degradado navy, logo centrado, form con email + password, botón de acceso
En modo demo: 3 botones de acceso rápido visibles debajo del form (Acceder como Admin / Asesor / Cliente)
Al montar: intentar auto-login como admin (demo mode) para navegación libre
Lock icon en header abre BottomSheet con selector de rol (demo switcher)
Rutas protegidas por rol con redirect a login si no autenticado
