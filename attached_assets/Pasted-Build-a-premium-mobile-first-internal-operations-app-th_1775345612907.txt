Build a premium mobile-first internal operations app that looks and behaves like a real native iPhone and Android financial control application.

USER STRUCTURE:
Create 4 very clearly defined roles.

1. GENERAL PUBLIC ROLE
This is a basic public access role or landing access.
Purpose:
- See company presentation
- Understand what the company does
- Contact the company
- See general business information
- View trust-building sections
- Optionally start a request or leave contact information
This role must NOT access internal portfolio data.

2. CLIENT ROLE
This is a simple client-facing role with limited access.
Purpose:
- View their own basic loan summary
- View payment schedule
- View current balance
- View next payment date
- View payment history
- View notices or reminders
- View company contact options
Do NOT make this role too complex.
It should be optional and lightweight.
No external integrations required.

3. EXECUTIVE ROLE
This is the operational field/desk executive role.
Each executive must only see their own assigned portfolio.
Functions:
- View assigned clients
- Search clients
- Register new clients
- Register loan data
- Register payments
- View current balance per client
- View payment number progress
- Detect overdue clients
- Register payment commitments
- Add notes and follow-up comments
- Upload client evidence
- Upload client photo
- Upload ID, CURP, proof of address, buro document scans if collected manually
- Register guarantor / aval data
- Register basic visit or follow-up logs
- See daily tasks and alerts
- See their own collection and placement stats
- See how much cash they currently hold in caja
- Every movement must be logged with timestamp and executive identity

4. ADMINISTRATOR ROLE
This is the master dashboard role.
Functions:
- Full access to all executives, clients, credits, payments, and reports
- Global portfolio view
- Portfolio segmented by executive
- Executive performance ranking
- View all recorded payments
- View caja by executive
- See overdue portfolio
- See current, overdue, and defaulted clients
- See operational semaforo by status
- Control users and permissions
- Detect inconsistencies
- Review audit trail of all movements
- Control business metrics and financial overview

CORE OBJECTIVE:
Replace the current fragmented workflow of Wallet App + Google Calendar + Excel with one single mobile-first internal control system.
